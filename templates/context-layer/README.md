# Context Layer

The company's knowledge, in plain files that people and AI can both read. Building it is step zero of a Context Sprint; keeping it current is the context keeper's job after every Sprint.

Copy this folder into your knowledge base (a notes vault, a docs folder in a repository, a shared drive) and connect it to the AI tools your team uses. Fill each file with what the company already knows. Short and true beats long and vague.

| File | What goes in it |
|---|---|
| `01-company.md` | What the company does, departments, roles, who decides what, glossary |
| `02-design-system.md` | Tokens, components, states, patterns, or a link to where they live |
| `03-brand-playbook.md` | Key visual, tone of voice, writing and presentation rules |
| `04-screens.md` | Every existing screen: name, purpose, users, where it lives |
| `05-decisions.md` | Product decisions and the reasons behind them |
| `06-stack.md` | Technologies, conventions, repository, how to run and test |

A company without a defined design system starts with a minimum one in `02-design-system.md` before running its first Sprint.
